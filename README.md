# BasketballPhysics

两个东西住在这个仓库里：一座投篮物理实验室（SHOT LAB），和把它游戏化的
对决小游戏（斗球实验室 SHOT DUEL）。纯 Python 标准库，零第三方依赖。

**定位：用手打出来的物理课。** 参数公开、答案固定、没有随机成分替你兜底——
练的是把物理读数变成肌肉记忆。这是整个项目栈的"执行"支柱。

## 快速上手

| 你想做什么 | 命令 |
|---|---|
| 玩单人挑战（蓄力+鼠标瞄准） | `python -m shotduel` |
| 两个人同屏对决 | `python -m shotduel --mode duel` |
| 没有图形环境时玩 | `python -m shotduel --cli` |
| 做物理实验（单次出手/命中率/参数扫描） | `python -m shotlab shot` / `mc` / `sweep` |
| 看三个经典出手 | `python -m shotlab demo` |
| 跑全部测试 | `python -m unittest discover -s tests` |
| 无头自检（CI/排障） | `python -m shotduel --selftest` |

## SHOT DUEL：为什么值得一玩

计分板不是"进/不进"，而是物理读数本身：偏心 3cm 以内且入射角落在
40°~55° 才是满分 PERFECT。三个输入通道彼此独立——

* 鼠标移动决定瞄准弧度（带平滑，滚轮/方向键可 0.25° 级微调）；
* 按住空格蓄力，2.8 秒充满（前快后慢，常用力度区约 3 m/s 每秒），
  过充会缓慢泄力；
* 左右方向键调后旋。

辅助瞄准常驻：出手点旁有 35°~65° 角度参考扇面，上一投以幽灵弹道
常驻显示，底栏教练行报出上一投的参数与结果——失败永远可以归因，
挑战在于"复现你做不到的那一投"，而不是盲猜。

每回合随机一个规则变体（风、移动篮筐、小筐、月球重力、浓雾等十种，
全部是真实物理参数），再抽一张变数卡——有好有坏，"打滑的手"让高手
也会手抖，"赌徒"得分翻倍但不中倒扣。双人对决的互动是物理的：
球进一次篮筐基座就漂移一截，输家挑下一块场地。

### Roguelike 单人模式

单人模式现在不是固定 5 投，而是一局最多 **10 个节点**：

- **3 点生命**：投丢会损失生命，生命归零立即结束本局；
- **筹码**：进球获得筹码，PERFECT 额外奖励，表现越好越能滚起雪球；
- **三选一构筑**：每个普通回合结束后选择一个本局升级，升级会持续到本局结束；
- **叠层**：稳定器、热手、旋转大师、柔和篮筐、风阻外套、高点出手等升级可以重复获得；
- **两个 Boss**：第 5、10 个节点会显著收紧物理条件，逼迫玩家根据自己的 build 调整出手；
- **种子可复现**：相同 seed 会得到相同的规则、技能和升级路径，方便挑战与调试。

因此重复游玩的目标从“再投一次”变成了“这局我要走什么构筑”：稳定执行、旋转路线、抗风路线、得分滚雪球，或者靠生命/筹码容错一路赌到 Boss。

## SHOT LAB：实验室模式

默认出手就是一记罚球线空心球。`shot` 命令输出轨迹画布、参数面板、
事件时间线，并附带蒙特卡洛命中率；`sweep` 画出速度×仰角的"命中岛"。

物理上值得一提的一点：模型算出罚球需要约 7.55 m/s 的出手速度，
与真实测量区间（7.3~7.9 m/s）吻合。引擎支持恒定风、篮筐简谐移动、
重力/筐径/筐高/球径/质量参数化，13 项引擎测试含解析解对照。

## 决策与依据（代码不难，难的是这些）

先说实话：RK4、恢复系数、圆-圆碰撞、蒙特卡洛，全是几十年前的教科书内容，
今天谁都写得出来。这个仓库真正花时间的不是代码，是下面几个决定——
每一个都有依据，有的还是被失败教出来的：

1. **计分板做成物理读数**（偏心 ≤3cm + 入射角 40°~55°）。反面是"爽快的分数"，
   多数篮球游戏选后者。选前者只有一个理由：失败必须能归因——差 2cm 和差 12cm
   是两种错法。
2. **物理必须对账才算数**。引擎算出罚球要 7.5 m/s，真实测量 7.3~7.9，对上之后
   "物理"才敢当卖点。这是验证动作，不是技术壁垒。
3. **手感问题当数学题解**。蓄力斜率除以人类反应时间，一个除法就解释了
   "为什么 1.1 秒蓄满反应不过来"；答案是把斜率压到执行噪声同量级。
4. **升级只改物理与执行条件，不凭空加命中率**。不然变强变成数字膨胀，
   物理课变页游。
5. **砍掉用不上的东西**。matplotlib 绘图路径环境里从没跑过——删了，
   仓库回到纯标准库。

## Web 物理原型 v0.3

第一版 Web 原型位于 `web/`，无需第三方依赖，直接用浏览器打开 `web/index.html` 即可体验。

当前只验证一件事：**“规划篮球轨迹”是否比单纯按空格投篮更有趣。**

- Canvas 2D 球场与基础投篮动画；
- 鼠标拖动控制角度与力量；
- 滚轮控制旋转；
- 虚线预测轨迹；
- 真实重力 + 简化弹性碰撞；
- 4 类基础障碍设计空间中的第一批实现：无障碍、弧高杆、反弹墙、方块通道，以及一个移动障碍关；
- Shooting Lab 记录距离、最高点、碰撞次数和结果。

这一版刻意没有加入商店、事件、Boss 和大量升级。先验证“角度 × 力量 × 旋转 × 障碍”这个核心循环，再把它接回 Roguelike。
