# 策划书 · 《斗球实验室 SHOT DUEL》

> BasketballPhysics 的游戏化版本。v1 策划案 · 2026-09
> 一句话：**这是唯一一款"物理读数就是计分板"的投篮游戏。**

---

## 1. 为什么玩这个游戏？（三大乐趣支柱）

设计要回答的核心问题：玩家为什么要打开它？

| 支柱 | 内容 | 对应设计 |
|---|---|---|
| 🧠 **物理直觉即技巧** | 没有角色等级、没有装备，唯一的成长是"你真的懂抛体运动了"。风、移动篮筐、低重力，全是真实物理，读得懂就能赢 | 规则变体全部建立在真实物理引擎上（RK4 + 阻力 + Magnus） |
| 🎯 **物理即计分** | 普通篮球游戏只判"进/不进"；本作用**偏心距 + 入射角**打分——空心入筐且入射角 40°~55° 才是满分 PERFECT。实验室的读数直接变成竞技的分数 | 计分系统（见 §5） |
| ⚔ **每局一个新世界** | 每一局规则变体不同：风、移动篮筐、小筐、月球重力、浓雾……玩家只能调"动作参数"，环境由天定 | 规则变体池（见 §4） |

**休闲与硬核的双轨**：随机性（规则抽签 + 技能抽卡）提供休闲趣味；
挑战性（无预瞄线的精确计分、连续命中倍率、双人博弈）提供硬核深度。
两种玩家都能找到自己打开它的理由。

## 2. 模式设计

### 2.1 单人 · 生存赛季（Solo Run）

- 一局 = **5 个回合**，每回合随机一个规则变体（不重复），基础距离逐回合拉远（罚球线 → 三分线）。
- 每回合开始抽 1 张**变数卡**（有好有坏，见 §6）。
- 计分：回合得分累加；**连续命中倍率**（连击 +1/次，上限 +2 分）制造"继续赌一把"的压力。
- 结束结算总评：⭐（未命中）~⭐⭐⭐（PERFECT），显示本局最佳纪录。

### 2.2 双人 · 同屏对决（Duel，热座）

突出**互动性**的三个机制：

1. **共用的篮筐会"记住"**：球进一次，篮筐基座就漂移一小段（+3~8cm，同一物理世界）。
   后出手的人面对的是被前一个人"打歪"的篮筐——干扰是物理的，不是数值的。
2. **输家挑场地**：上一回合的**输家**从 3 个候选规则变体中挑选下一回合的场地。
   落后的人获得翻盘杠杆（故意选自己擅长的，或选对手不擅长的）——博弈点。
3. **同条件同篮筐轮流出手**，回合得分高者拿 1 个回合胜场；**先拿 3 个回合胜场**赢下对决；
   2:2 后进入骤死局。

## 3. 核心循环

```text
回合开始
  ↓
🌍 规则变体揭晓（风/移动筐/小筐/月球…）
  ↓
🎴 抽 1 张变数卡（有好有坏）
  ↓
瞄准：拖拽蓄力（鼠标拖拽向量 = 力度+仰角）· Q/E 调后旋 · 空格出手
  ↓
🏀 火柴人起跳出手 → 球飞行（实时物理播放，风粒子/旋转球面/轨迹尾迹）
  ↓
结果结算：偏心 X cm · 入射角 Y° → PERFECT / 空心 / 弹框 / 打板 / 不中
  ↓
计分 → 下一回合（或交棒给对手）
```

**玩家能控制的只有动作参数**：出手力度、仰角、后旋（+拖拽决定的位置起点固定）。
环境全部来自规则变体与技能卡。

## 4. 规则变体池（每回合抽 1 个）

| 变体 | 图标 | 效果（全部是真实物理参数） | 难度 |
|---|---|---|---|
| 顺风 | 🌬 | 风向 +x（推向篮筐）约 1.2 m/s² | ★ |
| 逆风 | 🌫 | 风向 -x 约 -1.2 m/s²，必须加大力度 | ★★ |
| 疾风 | 🌪 | 风力 ±2.2 m/s²，方向随机 | ★★★ |
| 移动篮筐 | 🎪 | 篮筐（含篮板）水平正弦移动 ±0.18 m | ★★★ |
| 小筐 | 🧷 | 筐内径 ×0.72 | ★★★ |
| 月球重力 | 🌙 | g × 0.55，球飘得离谱 | ★★ |
| 铅球 | 🏋 | 球半径 ×1.25（阻力剧增、更沉） | ★★ |
| 远射 | 📏 | 距离 ×1.35（压哨三分） | ★★ |
| 浓雾 | 🌫 | **无瞄准预览、飞行轨迹不可见**，只有落点与结果 | ★★★ |
| 双重奏 | 🎭 | 随机叠两个上述变体 | ★★★★ |

## 5. 计分系统（物理计分，本作灵魂）

| 结果 | 条件 | 得分 |
|---|---|---|
| **PERFECT** ⭐⭐⭐ | 命中且 \|偏心\| ≤ 3cm 且入射角 40°~55° | **3 分** |
| 空心 SWISH | 命中且无任何接触 | 2 分 |
| 弹框/打板入筐 | 命中但有接触 | 1 分 |
| 不中 | — | 0 分 |
| 连击加成 | 连续命中第 n 球 | 额外 +min(n-1, 2) 分 |

结算面板展示完整物理读数（偏心 cm、入射角、入口速度），强化"实验室"身份。

## 6. 变数卡池（每回合抽 1 张，有好有坏——赌博的乐趣）

| 卡 | 类型 | 效果 |
|---|---|---|
| 🎲 幸运一步 | ✅增益 | 出手点前移 0.5 m（更近） |
| ↩️ 后撤一步 | ❌减益 | 出手点后移 0.5 m |
| 🌀 疾风加持 | ❌减益 | 当前风力 ×1.8 |
| 🎯 稳如老狗 | ✅增益 | 出手噪声 -60%（手感更稳） |
| 🐛 打滑的手 | ❌减益 | 出手噪声 +80%（手抖） |
| 👁 物理之眼 | ✅增益 | 本回合显示预测弹道虚线 |
| 💰 赌徒 | ⚠️混合 | 本回合得分 ×2，但不中扣 2 分 |
| 🏃 后旋加持 | ✅增益 | 后旋 +3 rad/s（更稳的弹道） |
| 🦾 沉重之球 | ⚠️混合 | 球质量 ×1.3：更抗风但更难投远 |
| 🧲 磁性篮筐 | ✅稀有 | 偏心 ≤ 8cm 时轻微向筐心吸附 |

噪声机制：确认出手时，实际参数 = 玩家输入 + 高斯噪声 ×(卡的噪声系数)。
"打滑的手"让高手也会翻车，"稳如老狗"是低配版保险——技能改变的是**执行误差**，
不是命中率数字，依然符合"物理即一切"的世界观。

## 7. 表现层（火柴人 + 2D 线条动画）

- **技术选型**：tkinter Canvas（Python 标准库自带，零依赖，线条渲染正是强项），30fps。
- **火柴人**：头部圆 + 躯干 + 四肢线段，5 组关键姿态（持球待机/瞄准/屈膝/起跳伸展/随挥），
  姿态插值动画；出手瞬间手臂沿出手方向伸展，球从指尖离开。
- **球**：飞行中画旋转的球面缝线（随 ω 自转），尾迹渐隐。
- **环境**：风用飘动的粒子线表示（密度 ∝ 风力）；移动篮筐整体平移（含篮板）；
  月球重力时球飞行时间自然拉长（物理自己会演）。
- **HUD**：回合数/规则名、风力表、篮筐状态、双方比分（对决模式）、连击、当前变数卡。
- **双人**：热座，交棒遮罩"把键盘交给 玩家 2"。

## 8. 操作（v0.2 重做：真操作手感，拒绝一键随机发射）

| 输入 | 动作 |
|---|---|
| 鼠标移动（画布） | **瞄准**：出手点到光标的方向 = 仰角弧度，实时显示角度与弹道虚线 |
| **按住空格** | **蓄力**：力度从 1.5 m/s 线性充能至 13.5 m/s（约 1.1 秒充满） |
| 持续按住（过充） | 满力后开始**缓慢泄力**（-0.25 m/s²，下限 60%）——犹豫就会泄掉 |
| 松开空格 | 出手（此刻的力度与鼠标角度一起锁定） |
| ← → | 后旋微调 ±0.5 rad/s |
| ↑ ↓ | 仰角微调 ±0.5°（鼠标瞄准的辅助） |
| Q / E | 后旋粗调 |

设计意图：力度=时间（肌肉记忆），角度=空间（鼠标弧度），后旋=策略（预判碰撞）。
三个输入通道互相独立，任何一环失手都会真实反映在物理结果上——
挑战性来自"执行力"，不是随机数。

**蓄力曲线**：`power(t) = t/1.1s`，充满后进入泄力区（计量条变红并抖动）。
默认不显示预测弹道，👁 物理之眼卡才能开启（蓄力过程中预测线实时跟随力度变化）。

## 9. 平衡与难度

- PERFECT 窗口（±3cm / 40°~55°）通过模拟器 Monte Carlo 标定：优秀玩家 PERFECT 率 ≈ 15~25%。
- 规则变体按 ★ 难度加权抽取，单人模式第 1 回合必抽 ★~★★，避免劝退。
- 对决模式先手/后手轮换（第 1 回合猜先），漂移量随机 — 消除绝对先手优势。

## 10. 里程碑

- **M1（本次）**：引擎扩展（风/移动筐/几何参数化）、规则池、变数卡池、物理计分、
  单人/双人逻辑、tkinter 火柴人 GUI、CLI 退化模式、自检脚本、测试。
- **M2**：更多变体（篮板弹力异常、时间减速）、双人技能对抗（干扰卡）、
  录制回放（复用轨迹数据）、最佳纪录持久化。
- **M3**：联网对战（同参数同种子竞速）、赛季挑战（每日固定种子）。

## 11. 风险

| 风险 | 对策 |
|---|---|
| tkinter 在部分环境缺失 | 提供 `--cli` 纯终端退化模式（同一套对局逻辑） |
| 移动篮筐下碰撞不稳 | 碰撞在每步用当前筐位解算，步长 2ms 远小于筐速位移 |
| PERFECT 太难/太简单 | §9 的 Monte Carlo 标定管线，参数集中在 scoring.py |
